# HUB FM27 - file per l'app "FM27 App Skin BeppEmre + Plugin"

Questo repository contiene SOLO i file che l'app scarica e controlla con le impronte (sha256).

| Dove | Cosa |
|---|---|
| `nofake/nofake27.json` + release `nofake` | i No Fake (FMScout, Sortitoutsi) |
| `skin/skin27.json` + release `skin` | la skin BeppEmre V 1.0: bundle, cartelloni, viste, licenze dei caratteri |
| `bepinex/bepinex27.json` + release `bepinex` | BepInEx, il caricatore dei plugin |
| `plugin/plugin27.json` + release `plugin` | i plugin FM27 di BeppEmre |

I No Fake sono di FMScout (fmscout.com) e Sortitoutsi (sortitoutsi.net): istruzioni e novita' sui loro siti.
BepInEx e' un progetto libero (github.com/BepInEx/BepInEx, licenza LGPL-2.1).
I caratteri usati hanno la licenza SIL Open Font License (testi nella skin, in licenze.zip, e dentro i plugin).
